01 / ABOUT

A companion that lives on your desk.

DESKEY combines an ESP32, SSD1306 OLED and RoboEyes-style expressions with a Windows Python awareness agent. Instead of being another app hidden behind a window, it turns your desktop activity into a small, visible physical interaction.

Python determines the current PC context and sends it to the ESP32 over Bluetooth Low Energy. The ESP32 turns that context into an animation, manages inactivity and sleep, tracks the Python heartbeat, and can fall back to autonomous behavior.

08 / FAQ

Questions, answered.

How does DESKEY work?+

DESKEY uses a Windows Python agent to understand your current PC activity, such as coding, browsing, typing and music. The agent sends the current state to the ESP32 over Bluetooth Low Energy. The ESP32 turns that state into an animated OLED expression, while also handling heartbeat, inactivity, sleep/wake and autonomous behavior if Python becomes unavailable.

Does DESKEY need Python all the time?+

No. Python provides PC awareness, but the ESP32 can operate independently. If Python stops communicating for 15 seconds, the ESP32 can switch to Autonomous Mode.

What happens when I stop using my PC?+

The ESP32 uses the reported PC idle time: after 30 seconds it becomes Sleepy, after 2 minutes Sleeping, and after 5 minutes it reaches the Deep Sleep animation.

What happens when I start using the PC again?+

DESKEY performs its wake animation, shows Happy, and then applies the current PC state reported by Python.

If Spotify is playing and I open VS Code, which animation wins?+

VS Code wins because foreground application context has priority over background audio. DESKEY should show Coding rather than Music.

Is “Deep Sleep” actual ESP32 deep sleep?+

Not currently. It is a DESKEY visual state. The ESP32 remains running so networking, the dashboard and heartbeat logic can continue.

How often can autonomous emotions change?+

The current autonomous event interval is randomized between 12 and 30 seconds.

What happens if the ESP32 is restarted?+

The Python BLE worker detects the lost connection, performs a fresh DESKEY discovery, reconnects automatically, and sends the latest PC state.

What happens if Bluetooth temporarily disconnects?+

PC activity detection continues while the BLE connection is retried in the background. When DESKEY is available again, the latest PC state is sent automatically.
